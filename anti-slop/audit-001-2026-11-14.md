# Anti-Slop Audit 001 — Shift Terakhir front page (2026-11-14)

Mode: after (audit; nothing modified). Scope: the app-style front screens added 2026-11-14
(menu / chapter list / about) in `index.html`, plus the front-page copy and the controls
they contain. Audited against antislop core v3.2.26 + antislop-ui + antislop-copywriting.
Priorities follow the rule tiers: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## Findings

1. **R-02 (HIGH)** — 9 em dashes (`—`) in front-page copy: the PERINGATAN note (1),
   both chapter descriptions (2), the About screen (6, incl. the how-to-play bullets).
   R-02 forbids the character in agent-written UI text outright.
   Fix: replace with commas, colons, or periods per sentence.

2. **R-25 (HIGH)** — Menu footer text `#68766f` on the scrim base `#05080a` measures
   **4.22:1**, below WCAG AA 4.5:1 for normal text (it is 9px). Every other front-page
   text pair passes (4.84:1 to 14.8:1). Fix: use `#75847a` (measured 5.11:1) or lighter.

3. **R-03 (HIGH)** — Tap targets below the 44px minimum on the front screens:
   sound button 31×31 (`.sound-btn`, shared with the chat head), the reset links
   (~14px tall text buttons), the profile name input (~24px tall).
   Fix: grow hit areas via padding/min-height without changing the visual design.

4. **R-39 (HIGH)** — No hover or active states on `.menu-row`, `.chapter-card`, or
   `.back-btn`. (Keyboard focus is covered: a global `button:focus-visible` 3px ring
   exists, and the name input swaps its underline color on focus.)
   Fix: add a subtle hover border/background shift and an active state.

5. **R-39 (HIGH)** — The profile name field has an `aria-label` but no *visible* label;
   the "PEGAWAI SHIFT MALAM" line above it is not associated with the input.
   Fix: make that line a real `<label for="profile-name">` (or add a visible label).

6. **R-01 (MEDIUM)** — The profile progress bar fill is a red→green two-hue gradient:
   decorative, no hierarchy purpose. (The MAIN row's dark-red gradient passes the
   purpose test: it marks the single primary action and carries the horror identity.)
   Fix: solid fill (brand green reads as progress).

7. **R-29/R-31 (LOW)** — Two accents run across the front: red (danger, kickers,
   primary action) and green (brand, status, progress). Defensible from the game's
   pre-existing identity (green = chat brand, red = horror warnings), and this audit
   is the written record of that reason. No change required unless the owner wants
   a single-accent discipline; finding 6 already removes the one place they mix.
